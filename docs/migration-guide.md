# Migration Guide 🔄

## Current Version

The Open Character Design Specification is currently in its initial release (v0.1). As this is the first public version, there are no prior versions to migrate from.

## Future Migrations

When new versions of the specification are released, this guide will be updated with:

- Breaking changes between versions
- Automated migration tools
- Step-by-step migration instructions
- Compatibility notes

If you're new to OCD, start with:

- [Quick Install Guide](getting-started.md) - Set up validators
- [First Character Tutorial](tutorial/first-character.md) - Create your first character
- [Field Reference](reference/fields.md) - Understand all available fields
