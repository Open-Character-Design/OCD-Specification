    JS/TS Validator¶

    The TypeScript/JavaScript validator provides full feature parity with the Python implementation, including schema validation, normalization, and diagnostics.

    Features¶

    • Ajv Integration: Full JSON Schema 2020-12 support
    • Normalization: Complete port of Python normalization logic
    • Diagnostics: All linting rules from Python implementation
    • Cross-Platform: Works in both Node.js and browser environments
    • API Parity: Consistent API with Python validator

    Installation¶

    Node.js¶

    npm install @ocs-tools/validator@1.0.0

    Browser¶

    <script src="https://unpkg.com/@ocs-tools/validator@1.0.0/dist/index.js"></script>

    Usage¶

    CLI¶

    # Validate a file
npx @ocs-tools/validator character.yaml

# Print normalized output
npx @ocs-tools/validator character.yaml --print

# Treat warnings as errors
npx @ocs-tools/validator character.yaml --warnings-as-errors

    Programmatic API¶

    import { validateAndNormalize } from '@ocs-tools/validator';

const result = await validateAndNormalize(document);

if (result.ok) {
  console.log('Valid:', result.data);
  console.log('Warnings:', result.warnings);
} else {
  console.log('Errors:', result.errors);
}

    Browser Usage¶

    // Load the validator
const { validateAndNormalize } = await import('@ocs-tools/validator');

// Validate a document
const result = await validateAndNormalize(characterData);

    API Reference¶

    validateAndNormalize(doc: unknown): Promise<Result<CoreDocument>>¶

    Validates and normalizes an OCS document.

    Parameters: - doc: The document to validate (JSON object)

    Returns: - Result<CoreDocument>: Object containing validation result

    Result Properties: - ok: boolean: Whether validation succeeded - data?: CoreDocument: Normalized document (if valid) - errors?: ValidationError[]: Validation errors (if invalid) - warnings: Warning[]: Linting warnings

    Types¶

    interface ValidationError {
  message: string;
  instancePath: string;
  schemaPath: string;
  keyword: string;
  params: Record<string, unknown>;
}

interface Warning {
  code: string;
  path: string;
  detail: string;
}
