## Getting Started

Canonical: `docs/getting-started.md` (rendered: `https://Open-Character-Design.github.io/OpenCharacter-Specification/getting-started/`)

Quick start (from repo root):

Python
```bash
cd python
pip install ocd
python ../tools/ocd-validate.py ../examples/bruenor.yaml --print
```

Node.js
```bash
cd node
npm install @ocd-tools/validator
npx @ocd-tools/validator ../examples/bruenor.yaml --print
```

- Spec: `spec/core.schema.json`
